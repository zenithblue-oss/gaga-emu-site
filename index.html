Engineered for Pure Compliance & Ultimate Performance

GagaEmu delivers 100% feature parity with premium iOS retro emulators while guaranteeing full adherence to App Store Review Guidelines.

No-JIT Interpreter Engine

Fully compliant with Apple W^X memory protection (Guideline 2.5.2). Employs direct-threaded instruction dispatch with tail-call optimization and ARM64 NEON SIMD intrinsics—zero executable code allocation.

[[clang::musttail]] • App Store 4.7 Ready

Native Metal 3 Shaders

Zero MoltenVK overhead. High-performance Metal Shading Language (MSL) pipelines stream UMA textures with real-time CRT scanlines, curved geometry, bloom, and RetroArch preset support.

MTLStorageModeShared • 60-120 Hz ProMotion

Multi-Core Orchestration

Hot-swappable emulator cores per platform. Select the optimal engine for each title—bsnes vs Snes9x, Beetle PSX vs PCSX-ReARMed, mGBA vs gpSP—with persistent per-game override settings.

Unified C-ABI Bridge (`GagaBridge`)

Complete Ingestion Hub

High-speed local WiFi HTTP upload server for dragging files from PC/Mac browsers, clipboard ROM extraction, MultiDisc M3U playlist manager, and in-memory IPS/BPS/UPS soft-patcher.
